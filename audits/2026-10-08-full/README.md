## Что работает

Нормативная структура `2026-09`, freshness rules/schema/coverage, revision lock,
projection catalog и semantic manifest проходят проверки. В semantic parity уже
есть восемь семейств; старое замечание «сравниваются только error codes» более не
соответствует коду.

Штатные PHP-тесты: **254 tests / 674 assertions**, включая PostgreSQL-тесты на
специально созданной базе. Dart core: **217 tests**, MCP companion: **7 tests**.
PHPStan и оба `dart analyze --fatal-infos` зелёные.

Интегральный `ci_gate.py --all` прошёл в временной копии с установленными
зависимостями: **213/213** candidate cases у каждого из reference/PHP/Dart,
frozen regression и harness checks. Официальный MCP runner: **7/7 применимых**, из
**32** frozen required client scenarios. Это не означает покрытие остальных 25.

Adversarial corpus: **29 cases**; mutation catalog: **26 killed / 0 survived**;
live PostgreSQL schedules зелёные. Resource probes также дали green, но aggregate
и запись полного resource gate не прошли. Подробные оговорки — в методике.

## Главная рекомендация

Следующая работа должна закрыть реальные сквозные пути: сценарий → подтверждение
→ идемпотентный вызов → сохранение → загрузка → восстановление → компенсация.
Количество изолированных зелёных проверок уже велико; нужно добавить наблюдаемые
инварианты между этими компонентами и независимые отрицательные примеры.

Дефекты A01–A12 находятся в коде, совпадавшем с HEAD на момент аудита. A13 и A19
нужно рассматривать в контексте незавершённой миграции рабочего дерева, не приписывая
их автоматически базовому commit. Папки прежних планов существуют частично:
проблема в исчезнувших Markdown contracts/findings при сохранившихся hardcoded paths
и части JSON artifacts.
