# Compiler examples

Generated by `php packages/agentools-core/tests/Context/generate.php`.
`snapshot.json` and `provenance.json` pin a scripted history/skill/route input;
`overflow.json` demonstrates 5600 mandatory tokens versus 5500 allowance;
`text-voice.json` uses the same pinned input for text and a decoded voice delta.
These are contract-scripted synthetic examples, not provider or voice qualification.
The byte-count adapter is versioned and conservative. No full prompt, raw tool
rows, secret or plaintext diagnostics are persisted in these examples.
