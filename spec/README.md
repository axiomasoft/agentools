# spec/

Нормативная спецификация AgenTools. Ревизии — датированные, immutable после
релиза (паттерн Model Context Protocol): пока ревизия в разработке, она живёт
в `revisions/<YYYY-MM>-draft/`; после стабилизации (все SDK зелёные на её
fixtures) переименовывается в `revisions/<YYYY-MM>/` и больше не редактируется —
следующие изменения идут в новую ревизию.

Каждая ревизия содержит нормативные документы (`NN_<slug>.md`, пронумерованные
правила вида `TCP-1`, `LC-1`, …) и соответствующие JSON Schema (`schema/*.json`,
draft 2020-12). Документ описывает СЛОВАМИ то, что схема описывает СТРУКТУРОЙ —
оба обязаны быть согласованы; расхождение — дефект ревизии.

Текущая ревизия: `revisions/2026-07-draft/` (в разработке).
