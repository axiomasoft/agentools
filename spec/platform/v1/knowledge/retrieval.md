# Optional retrieval boundary

P8.1 implements ingest, validation, release persistence and local invalidation.
The optional P8.2 `Knowledge\Retrieval` module adds local lexical/semantic adapters,
rank fusion, rerank, extractive selection and buffered disclosure. The host wires
the repository, current `MaterialAccessPolicy`, exact-source `SourceAvailability`
and `Clock`; installing the package does not register routes or call providers.

A retrieval request carries trusted tenant, subject/audience, purpose, required
scopes, allowed exact corpus/releases, locale/program metadata and normalized
query hash. Filter tenant/rights/audience/version **before** candidate adapters.
Use exact release references and embedding spaces. Lexical and semantic candidates
are reranked, overlap/diversity deduplicated and reduced to the minimum sufficient
fragment. Source/version/page/range/hash, validation status, rights references,
release hash and space accompany each fragment. `EvidenceSet` binds to a Run;
retrieval is not automatic memory or permission to disclose.

After candidate selection, recheck local invalidation and fresh owner permissions
immediately before disclosure, including cache hits and pinned releases. Permission
checks at ingest or candidate retrieval do not authorize later disclosure.
Unavailable, unknown or empty retrieval produces a typed outcome with no evidence;
the host must limit its answer, clarify or refuse without a synthetic citation.
`fixtures/platform/v1/retrieval/evidence.json` is generated by the local contract
harness. The earlier `knowledge/evidence.json` remains a P8.1 design example.

`Service::retrieve(Query)` returns a reference-only `Selection`, with a binding to
the exact query and Run. `Service::disclose(Query, Selection)` resolves immutable
source text and performs fresh repository, permission and source-existence checks
after cache/rerank/selection and again at the final boundary. Call it at each actual
buffered disclosure boundary, including a later segment using a cached selection.
The returned `EvidenceSet` is an immutable historic observation, never a reusable
permission grant. Hosts must not release an old result or its `toolView()` without
a new disclosure check. Correction/revoke blocks new uses without rewriting history.

`Query` uses trusted `Scope`, Run, allowed exact `ReleasePin` values (corpus, release,
hash, material/version and host program metadata), locale and optional embedding
space. Query normalization v1 collapses Unicode whitespace and folds ASCII case;
its hash and complete scope, allowlist, metadata, space and limits partition the
cache. Cache entries may be reused across Runs only after fresh checks and rebinding.
Subject, purpose, audience and scope changes change the cache key. Hosts clear the
bounded `ArrayCache` in worker/job reset; a cache hit never supplies source text.
The host must change the service revision when rank/index policy changes.

Search adapters receive only authorized release objects and must constrain their
underlying search before ranking. The local lexical adapter ranks term overlap;
the optional semantic adapter scores host-supplied vector records with cosine
similarity in one exact provider/model/revision/dimensions/normalization/index
version. Supplying a semantic adapter requires explicit `EmbeddingTransport`.
The full space is checked before embedding/search, after index lookup and before
disclosure; equal dimensions never allow substitution. Even lexical-only retrieval
honors an explicitly supplied space pin. No default provider or dimension is fixed.

Reciprocal-rank fusion combines lexical/semantic candidates. An optional reranker
may reorder or remove existing references, never add references or expand ranges.
Candidates and cache hits are resolved against allowed release hashes and validated
fragment/source/page/content hashes; adapters cannot provide citation text. Selection
prefers query-matching sentences or UTF-8-safe byte windows, deduplicates overlap and
identical text and gives distinct materials priority. Limits are 1–8 fragments,
32–8192 total bytes and 32–1024 bytes per fragment; defaults are 3/2048/512.
This extractive heuristic bounds evidence size; semantic or pedagogical sufficiency
remains host/Edufy policy.

`EvidenceSet` retains source/version/coordinates/hashes, rights refs, complete space
or explicit null and checked/expiry times. Its `toolView(OwnerViews)` returns compact
untrusted `model_view`, evidence/freshness and tenant-matched host-owned raw/user/audit
refs. Raw payloads are never loaded or persisted here; memory activation stays false.
Outcomes distinguish success, empty, denied, unknown, unavailable and incompatible
(`SPACE_MISMATCH`), with no fragments on unsuccessful outcomes. Adapter exception
messages are suppressed. The selection TTL is 1–300 seconds, default 30; it never
replaces a current owner check.

The plain text extractor and scripted owner fixtures prove local contracts, not
external Library/Files readiness, live provider support or production readiness.
