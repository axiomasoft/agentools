### P2.1 — Корпус проб bakeoff: 10 конструкций 2020-12 + шкала вердиктов

**Intent:** Собрать воспроизводимый корпус проб: по одной минимальной схеме на каждую конструкцию JSON Schema 2020-12, которую наши схемы реально используют или могут использовать, плюс к каждой — валидный документ и документ с незнакомым ключом; зафиксировать шкалу вердиктов прогона.
**Why:** Без общего корпуса результаты PHP- и Dart-прогонов несравнимы, а вердикт «ключевое слово разрешено» становится вкусовым. Корпус переиспользуется как регрессионные пробы кодогенерации в CI (`DR-01` §J5, слой «свежесть кодогенерации»). `RAG:✅ 2026-07-26 R-11 §10: полное покрытие draft 2020-12 не подтверждено ни у PHP-генератора, ни на стороне Dart — зрелого schema-first генератора нет`.
**Scope Included:** 10 проб по `research/01-target-structure-2026-08.md` §3 (`p01-open-enum`, `p02-unknown-keyword`, `p03-unevaluated`, `p04-dynamic-ref`, `p05-defs-allof`, `p06-if-then-else`, `p07-prefix-items`, `p08-nested-depth`, `p09-ref-local`, `p10-numbers`); каждая проба — каталог `bakeoff/probes/<id>/` с файлами `schema.json` (минимальная схема, диалект 2020-12, `$id` локальный), `valid.json` (документ, проходящий схему), `unknown-key.json` (тот же документ + одно неизвестное свойство и, где применимо, неизвестный ключ схемы), `README.md` (что проверяет проба, какое поведение считается терпимым); `bakeoff/README.md` — метод прогона и **шкала вердиктов (закрытое перечисление)**: `ok` (конструкция понята), `ignored-gracefully` (не понята, но прогон успешен и поля не потеряны), `field-lost` (прогон успешен, но поле исчезло из сгенерированного типа/round-trip), `crash` (генератор упал), `not-supported` (кандидат не имеет такого таргета/не устанавливается); `bakeoff/.gitignore` (D34) — исключает `php/vendor/`, `*/.dart_tool/`, `*/build/` и **переисключает** логи прогонов строками `!results/*.log` и `!dart-transport/*.log` (иначе корневой шаблон `*.log` делает `git add` логов молчаливым no-op'ом; переисключение покрывает ВСЕ каталоги логов фазы сразу — чтобы ни один следующий item не правил чужой файл), lock-файлы песочниц (`composer.lock`, `pubspec.lock`) НЕ игнорируются — они доказательство прогнанных версий.
**Scope Excluded:** сами прогоны генераторов (P2.2/P2.3); транспорт (P2.4); любые правки схем ревизии; выбор списка разрешённых ключевых слов (P2.5 по фактам); правка корневого `.gitignore` репозитория (D34 — только вложенный).
**Inputs:** `research/01-target-structure-2026-08.md` §3 (таблица проб) · `10_decisions/DR-01_architecture-2026-08.md` §E2 (открытые перечисления), §E5 (схемная гигиена + ограничения SEP-2106), §J9 (две схемы) · `findings/P2-bakeoff-recon-2026-07-27.md` §4 (механика вложенного `.gitignore`, репро) · `spec/revisions/2026-07-draft/schema/` — образец реальных конструкций, которые мы уже применяли (только чтение).
**Files:** `bakeoff/README.md` · `bakeoff/.gitignore` · `bakeoff/probes/p01-open-enum/**` … `bakeoff/probes/p10-numbers/**` (репо-пути — от корня `~/projects/packages/agentools`, см. «Раскладка по репозиториям» в Phase Context)
**Required Reads:** 1) `05-Projects/03-Packages/AgenTools/plans/AGENTOOLS/research/01-target-structure-2026-08.md` §3 2) `05-Projects/03-Packages/AgenTools/plans/AGENTOOLS/10_decisions/DR-01_architecture-2026-08.md` §E2, §E5, §E6, §J6, §J9 3) `05-Projects/03-Packages/AgenTools/plans/AGENTOOLS/findings/P2-bakeoff-recon-2026-07-27.md` §4 4) `spec/revisions/2026-07-draft/schema/side-effect.json` и `schema/scenario.json` (образцы применяемых конструкций) 5) `05-Projects/03-Packages/AgenTools/plans/AGENTOOLS/plan.md` §2 Execution Rules.
**Implementation Rules:** схемы проб — минимальные (одна конструкция на пробу, никаких «богатых» примеров); диалект — `https://json-schema.org/draft/2020-12/schema` явно в каждой схеме; `$id` — локальный (`https://agentools.dev/bakeoff/<probe>/schema.json`), сетевых `$ref` нет вовсе (`DR-01` §E5); все JSON-файлы — UTF-8 без BOM, LF, ровно один завершающий перевод строки; тексты `README.md` — русские, объясняют «почему проба важна», а не «что в файле»; `bakeoff/.gitignore` пишется ДО первого прогона (иначе следующие items потеряют логи молча) и проверяется командой `git check-ignore`, а не чтением глазами.
**Code Guidance:** Кода нет — данные и метод. Анти-подгонка (contract-item): корпус пишется под РЕАЛЬНЫЕ конструкции спеки и `DR-01`, а не под то, что кандидаты заведомо умеют; ЗАПРЕЩЕНО убирать пробу из корпуса потому, что «генератор её всё равно не переживёт» — именно такой факт и является результатом фазы. Шкала вердиктов закрытая: новые значения не изобретать, непокрываемый случай → эскалация. Анти-самообман по игнорированию: «файл лежит на диске» ≠ «файл попадёт в item-коммит»; критерий — `git ls-files`/`git check-ignore`, а не `ls`. If-then: конструкция из `research/…` §3 не встречается ни в одной схеме ревизии и не предполагается `DR-01` → пробу оставить, но пометить в её `README.md` «гипотетическая, влияет только на схемы авторинга» — чтобы P2.5 не поднял её в блокирующий критерий. If-then: переисключение `!results/*.log` не срабатывает на местной версии git → НЕ переименовывать логи в обход и НЕ править корневой `.gitignore`: зафиксировать факт и эскалировать (trigger «rule conflict», D34 — решение владельца).
**Validation:** `ls -d bakeoff/probes/*/ | wc -l` = 10 · `for d in bakeoff/probes/*/; do test -f "$d/schema.json" -a -f "$d/valid.json" -a -f "$d/unknown-key.json" -a -f "$d/README.md" || echo "НЕПОЛНАЯ: $d"; done` — вывод пуст · `python3 -c "import json,glob; [json.load(open(f)) for f in glob.glob('bakeoff/probes/*/*.json')]"` — без ошибок · `grep -L 'json-schema.org/draft/2020-12/schema' bakeoff/probes/*/schema.json` — вывод пуст · `grep -c 'ignored-gracefully' bakeoff/README.md` ≥ 1 (шкала зафиксирована) · `mkdir -p bakeoff/results && touch bakeoff/results/_probe.log && git check-ignore -q bakeoff/results/_probe.log; echo $?` = 1 (лог НЕ игнорируется), затем `rm bakeoff/results/_probe.log` · `git check-ignore -q bakeoff/php/vendor/x 2>/dev/null; echo $?` = 0 (песочный vendor игнорируется).
**Deliverables:** 10 проб (по 4 файла) + `bakeoff/README.md` с методом и закрытой шкалой вердиктов + `bakeoff/.gitignore`, доказанный командами `git check-ignore`.
