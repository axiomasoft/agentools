# P11 — Release & Hygiene: чистый публичный пакет и воспроизводимый кандидат

## Phase Context

P11 — терминальная инженерная фаза после P10. Она не расширяет семантику протокола и не создаёт
интеграции с Chatom, AzGuard или CoreX. Её цель — доказать, что PHP/Dart-артефакты можно передать
потребителю как чистые нативные пакеты: публичная поверхность намеренна, документация правдива,
проверки воспроизводимы, а пакет не содержит следов фазового процесса.

> **Контракт фазы.** Потребляет: frozen ревизию, conformance-гейты P6–P8, результаты срезов
> P9/P10, `root/contracts/package-quality-baseline.md` (P5.3), package manifests и README.
> Производит: release-candidate evidence, API manifests, reconciliation публичных документов и
> итоговый hygiene verdict. Границы: не меняет семантику спеки, не выпускает без owner-approved
> publication decision, не добавляет framework bridge и не делает reference-проекты зависимостями.

**Порядок исполнения.** P11.1 → P11.2 → P11.3 → P11.4. Любой semantic/API defect возвращается
в owning phase P6–P10; P11 не маскирует его changelog-правкой.

### P11.2 — Явная публичная API-поверхность и документация

**Status:** ⬜ Not started
**Intent:** Сформировать PHP/Dart API manifests и привести README/usage examples к фактическим exports без phase labels или внутренних reference-проектов.
**Why:** Conformance доказывает поведение, но не доказывает, что пользователь видит маленькую намеренную API. `RAG:— (repo-grounded: research/11-package-quality-and-release-architecture-2026-08.md)`.
**Scope Included:** manifest экспортов для PHP и Dart; проверка каждого stable API по правилу «export + production consumer + behavioural test»; документация установки, минимального использования, совместимости и границ core/transport.
**Scope Excluded:** новые stable contracts без потребителя; изменение протокольной семантики; публикация пакета.
**Inputs:** P7/P8 source/tests · conformance reports · `root/contracts/package-quality-baseline.md` · P11.1 identity evidence.
**Files:** `php/API.md` · `dart/agentools/API.md` · package README/examples · `artifacts/P11-public-api.md`.
**Required Reads:** 1) `root/contracts/package-quality-baseline.md` 2) P7.12/P8.13 gate reports 3) package public source and tests.
**Implementation Rules:** В manifest попадает только реально экспортируемое. Каждый пункт содержит путь consumer-теста; отсутствующий consumer означает internal/remove/escalate, не «задокументировать позже». Phase IDs не попадают в публичные package docs or API names.
**Code Guidance:** Examples используют только public API и не импортируют internal `src` paths.
**Validation:** каждый manifest entry имеет consumer-test path и существует · `rg -n "P[0-9]+\\.|phase [0-9]|Chatom|AzGuard" php/README.md php/API.md dart/README.md dart/agentools/API.md` = 0 · examples собираются/тестируются package-native командами · плановый линтер, K = 0.
**Deliverables:** API manifests, truthful public docs and executable examples.

### P11.3 — Воспроизводимый clean-checkout quality gate

**Status:** ⬜ Not started
**Intent:** Проверить релизный кандидат из чистого checkout одним оркестратором `tools/ci_gate.py` с прозрачными package-native командами.
**Why:** Локально зелёное загрязнённое дерево не является доказательством релизного качества. `RAG:— (repo-grounded: research/11-package-quality-and-release-architecture-2026-08.md)`.
**Scope Included:** isolated clean checkout; Composer/Pub install; formatting, static analysis, unit/architecture tests, conformance, API/doc drift checks и inventory package artefacts; machine-readable report.
**Scope Excluded:** новые CI-драйверы, фреймворк/DB matrix, сеть к production service, публикация registry.
**Inputs:** P11.1/P11.2 deliverables · `tools/ci_gate.py` · package manifests/locks · conformance reports.
**Files:** `tools/ci_gate.py` (только если ему не хватает уже определённой проверки) · `artifacts/P11-clean-checkout.md`.
**Required Reads:** 1) `root/contracts/package-quality-baseline.md` 2) `tools/ci_gate.py` 3) P7.12/P8.13 gates 4) P11.2 API manifests.
**Implementation Rules:** Не заводить второй shell/CI orchestrator. PHP matrix ограничена поддерживаемыми PHP versions; Dart commands: `dart format --output=none --set-exit-if-changed .`, `dart analyze`, `dart test`. Если проверка требует framework/DB, это scope leak и результат `🔴 Blocked`.
**Code Guidance:** Gate сообщает конкретный violated contract и не скрывает ошибки через filter/baseline.
**Validation:** clean checkout создаётся вне исходного дерева и report называет commit/commands/exit codes · `python3 tools/ci_gate.py --all; echo $?` = 0 · PHP formatter/analyser/tests и Dart format/analyze/test зелёные · report показывает, что public docs не содержат phase/reference leakage · плановый линтер, K = 0.
**Deliverables:** воспроизводимый clean-checkout report and one authoritative quality-gate entry point.

### P11.4 — Release candidate и независимый consumer smoke

**Status:** ⬜ Not started
**Intent:** Собрать versioned release candidate, прогнать минимальных независимых потребителей PHP/Dart и выдать терминальный hygiene verdict.
**Why:** Внутренние тесты могут одновременно разделять одну ошибку; consumer smoke доказывает фактическую установку и публичный путь. `RAG:— (repo-grounded: findings/R-12-package-quality-reference-2026-08.md)`.
**Scope Included:** версия/changelog/release notes по resolved Q-30; установка PHP и Dart artefacts в два минимальных standalone consumers; public API example; итоговый `PASS|BLOCKED` verdict с версией и commit.
**Scope Excluded:** реальный релиз в registry без отдельного owner authorization; потребление через Chatom/AzGuard/CoreX; изменение API для прохождения smoke.
**Inputs:** P11.1–P11.3 deliverables · API manifests · release decision Q-30.
**Files:** `CHANGELOG.md`/release notes as selected by Q-30 · `artifacts/P11-release-candidate.md`.
**Required Reads:** 1) P11.1–P11.3 deliverables 2) `root/contracts/package-quality-baseline.md` 3) public README/API manifests.
**Implementation Rules:** Consumers use only installed package public APIs and no workspace path import after install. Smoke failure returns to owning phase; no local patch in consumer. If publication authorization absent, candidate is local and verdict says so explicitly.
**Code Guidance:** Consumer examples remain minimal and product-neutral; no framework bootstrapping.
**Validation:** both standalone consumers install the candidate and run one documented public scenario with exit 0 · candidate version is identical across metadata/changelog/report where applicable · `rg -n "Chatom|AzGuard|CoreX|P[0-9]+\\."` consumer sources = 0 · `artifacts/P11-release-candidate.md` contains exactly one `**Вердикт: PASS**` or `**Вердикт: BLOCKED**` · plan lint, K = 0.
**Deliverables:** versioned candidate, two independent consumer-smoke transcripts and terminal hygiene verdict.
