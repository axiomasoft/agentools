### P8.12 — Транспорт: порт `McpTransport` + пакет-спутник `agentools_mcp_dart`, триггер T-1, находка F7

**Intent:** Завести в ядре минимальный порт `McpTransport` (вместе с его единственным потребителем — §E6) и реализовать его в ОТДЕЛЬНОМ пакете `dart/agentools_mcp_dart/` поверх `mcp_dart` по вердикту `DR-02` §5; СНЯТЬ триггер T-1 (`DR-02` §7) проверкой ФУНКЦИОНАЛЬНОСТИ пина, а не номера версии; ЗАКРЫТЬ находку F7 (D52) закоммиченным логом отрицательного прогона, доказывающим, ЧТО ИМЕННО энфорсит `resultType`.
**Why:** Это единственный item фазы с ОТКРЫТЫМИ решениями, и все три — с необратимой ценой ошибки. Первое: **T-1 нельзя закрыть по номеру версии.** Разведка 2026-07-27 показала, что stable `mcp_dart` 2.2.2 не содержит НИ `McpProtocol.require2026`, НИ энфорсмента `resultType` (греп по исходникам обеих версий: 0 совпадений в stable, `lib/src/types/json_rpc.dart:48,68,73,83,90` и `lib/src/shared/protocol.dart:790` в prerelease `2.3.0-dev.3`) — то есть «уйти на stable ради стабильности» ПОТЕРЯЛО БЫ обе возможности, и вердикт по T-1 обязан опираться на наличие функциональности в исходнике пина. Второе: **F7 — про класс доказательства, а не про факт.** Утверждение «`resultType` энфорсится клиентом» верно по существу (в нашем 26-строчном клиенте `client-mcp-dart/main.dart` проверки нет вовсе, значит отказ пришёл из библиотеки), но в item-коммите `4344265` НЕТ лога упавшего прогона — `grep -rn resultType` по всем логам bakeoff даёт 0 совпадений. Пока лога нет, защита существует «со слов», и её исчезновение в следующей версии зависимости никто не заметит. Третье: **форма порта.** Порт, выведенный из API `mcp_dart`, протащил бы prerelease-контракт в публичную поверхность ядра — и решение D86 «транспорт отдельным пакетом» стало бы формальным разделением каталогов при фактической связке. `RAG:✅ 2026-07-27 (pub.dev/packages/mcp_dart + /versions: stable 2.2.2 — ≈30 дн., prerelease 2.3.0-dev.3 — ≈4 дн., 46 версий, MIT, Dart SDK ^3.0.0; README stable заявляет протокол 2025-11-25 с обратной совместимостью до 2024-10-07, ни 2026-07-28, ни require2026 не упоминает)` · `RAG:— (repo-grounded: findings/P8-dart-sdk-recon-2026-07-27.md §5, §6 — греп по исходникам stable и prerelease, греп по логам bakeoff, содержимое обоих клиентов прототипа; findings/P2-dart-transport.md — критерии и вердикт P2.4; plan.md §5 D39, D52, D86; DR-02 §5, §7)`.
