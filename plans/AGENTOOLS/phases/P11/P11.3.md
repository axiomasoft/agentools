### P11.3 — Воспроизводимый clean-checkout quality gate

**Intent:** Проверить релизный кандидат из чистого checkout одним оркестратором `tools/ci_gate.py` с прозрачными package-native командами.
**Why:** Локально зелёное загрязнённое дерево не является доказательством релизного качества. `RAG:— (repo-grounded: research/11-package-quality-and-release-architecture-2026-08.md)`.
**Scope Included:** isolated clean checkout; Composer/Pub install; formatting, static analysis, unit/architecture tests, conformance, API/doc drift checks и inventory package artefacts; machine-readable report.
**Scope Excluded:** новые CI-драйверы, фреймворк/DB matrix, сеть к production service, публикация registry.
**Inputs:** P11.1/P11.2 deliverables · `tools/ci_gate.py` · package manifests/locks · conformance reports.
**Files:** `tools/ci_gate.py` (только если ему не хватает уже определённой проверки) · `artifacts/P11-clean-checkout.md`.
**Required Reads:** 1) `root/contracts/package-quality-baseline.md` 2) `tools/ci_gate.py` 3) P7.12/P8.13 gates 4) P11.2 API manifests.
**Implementation Rules:** Не заводить второй shell/CI orchestrator. PHP matrix ограничена поддерживаемыми PHP versions; Dart commands: `dart format --output=none --set-exit-if-changed .`, `dart analyze`, `dart test`. Если проверка требует framework/DB, это scope leak и результат `🔴 Blocked`.
**Code Guidance:** Gate сообщает конкретный violated contract и не скрывает ошибки через filter/baseline.
**Validation:** clean checkout создаётся вне исходного дерева и report называет commit/commands/exit codes · `python3 tools/ci_gate.py --all; echo $?` = 0 · PHP formatter/analyser/tests и Dart format/analyze/test зелёные · report показывает, что public docs не содержат phase/reference leakage · плановый линтер, K = 0.
**Deliverables:** воспроизводимый clean-checkout report and one authoritative quality-gate entry point.
