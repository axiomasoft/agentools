### P11.2 — Явная публичная API-поверхность и документация

**Intent:** Сформировать PHP/Dart API manifests и привести README/usage examples к фактическим exports без phase labels или внутренних reference-проектов.
**Why:** Conformance доказывает поведение, но не доказывает, что пользователь видит маленькую намеренную API. `RAG:— (repo-grounded: research/11-package-quality-and-release-architecture-2026-08.md)`.
**Scope Included:** manifest экспортов для PHP и Dart; проверка каждого stable API по правилу «export + production consumer + behavioural test»; документация установки, минимального использования, совместимости и границ core/transport.
**Scope Excluded:** новые stable contracts без потребителя; изменение протокольной семантики; публикация пакета.
**Inputs:** P7/P8 source/tests · conformance reports · `root/contracts/package-quality-baseline.md` · P11.1 identity evidence.
**Files:** `php/API.md` · `dart/agentools/API.md` · package README/examples · `artifacts/P11-public-api.md`.
**Required Reads:** 1) `root/contracts/package-quality-baseline.md` 2) P7.12/P8.13 gate reports 3) package public source and tests.
**Implementation Rules:** В manifest попадает только реально экспортируемое. Каждый пункт содержит путь consumer-теста; отсутствующий consumer означает internal/remove/escalate, не «задокументировать позже». Phase IDs не попадают в публичные package docs or API names.
**Code Guidance:** Examples используют только public API и не импортируют internal `src` paths.
**Validation:** каждый manifest entry имеет consumer-test path и существует · `rg -n "P[0-9]+\\.|phase [0-9]|Chatom|AzGuard" php/README.md php/API.md dart/README.md dart/agentools/API.md` = 0 · examples собираются/тестируются package-native командами · плановый линтер, K = 0.
**Deliverables:** API manifests, truthful public docs and executable examples.
