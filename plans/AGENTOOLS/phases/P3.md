# P3 — Dart SDK v0.1 (`agentools`) — зелёный на fixtures

## Phase Context

Второй нативный порт спеки — pub-пакет `agentools` (Dart ≥3.7, pure Dart, без Flutter-зависимостей).
Зеркалирует структуру PHP SDK (P2 — референс: где Dart-решение неочевидно, смотреть, как решено
в PHP, но писать идиоматичный Dart, не транслит). Ключевое отличие контура: SDK обязан
встраиваться в контракты AxiomaErpSdk — `axioma_assistant` (AssistantOrchestrator/IntentRouter)
и `axioma_mcp` (AxiomaTool, tier) — поэтому порты проектируются со швом под них (см. R-00 Грань A),
но сам SDK от Axioma НЕ зависит (направление зависимости: Axioma → agentools). Scenario Runner
закрывает известный гэп Axioma «LlmResponse = одиночный toolCall» как расширение поверх портов.
Финал фазы: conformance-адаптер dart-sdk зелёный на L1+L2 (та же планка, что P2.8), тесты зелёные,
`dart analyze` без ошибок. Conformance-уровни позволяют асимметрию (D7 плана), но целевая планка
фазы — паритет L1+L2.
