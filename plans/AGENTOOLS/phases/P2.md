# P2 — PHP SDK v0.1 (`agentools/sdk`) — зелёный на fixtures

## Phase Context

Первая нативная реализация спеки (PHP-first, D14). Пакет `agentools/sdk` (namespace
`AgenTools\`, PHP ≥8.3) — ТОНКАЯ библиотека: контракты (интерфейсы), value objects,
FSM сессии, confirmation-движок, scenario-runner, idempotency/audit — БЕЗ привязки к
Laravel/CoreX (интеграция в corex/ai — фаза P4, через package-contribution-протокол).
LLM и доменные tools подключаются через порты (интерфейсы) — SDK не знает, что за ними
AiGateway или laravel/mcp. Персистентность — контракты + in-memory реализации (D13 плана).
Финал фазы: `conformance/bin/run` с адаптером php-sdk зелёный на всех L1+L2 векторах,
юнит-тесты зелёные, phpstan level max без ошибок. Каждый item пишет тесты вместе с кодом.

Дисциплина: любые расхождения спеки с реализуемостью — эскалация в план (не молчаливая
правка спеки); правка спеки = отдельный мини-цикл с прогоном spec_lint и заметкой в
Update Log плана.

**Why:** Всё дальнейшее строится на этих типах; JCS — фундамент idempotency и golden-тестов.
**Scope Included:** enum'ы PHP 8 для закрытых списков (states, side_effect, categories…); fromArray/toArray с валидацией против схем ревизии (schema-файлы читаются из репо, путь конфигурируем); JCS: если пин R-08 дал библиотеку — тонкая обёртка, иначе собственная реализация RFC 8785 по изложению из 05_audit-events.md; тесты: golden-пары из `fixtures/golden/jcs/` обязаны проходить; негативные тесты валидации (лишнее поле → ошибка).
**Scope Excluded:** поведение (FSM, движки); сериализация в БД.
**Inputs:** схемы `spec/revisions/2026-07-draft/schema/*.json`; golden-пары.
**Files:** `php/src/Value/**`, `php/src/Schema/**` (валидатор+лоадер), `php/src/Canonical/Jcs.php`, `php/tests/**`
**Required Reads:** 1) spec/revisions/2026-07-draft/schema/*.json (все) 2) 05_audit-events.md (JCS-раздел) 3) fixtures/golden/jcs/* 4) R-08 (валидатор).
**Implementation Rules:** readonly-классы/enums; исключения — свои типизированные (`AgenTools\Exception\…`), тексты на русском; никакого reflection-маппинга «умных» библиотек — ручной fromArray (тонко и прозрачно).

**Validation:** pest+phpstan зелёные; golden-JCS тесты проходят; негативные тесты валидации присутствуют (≥5).
