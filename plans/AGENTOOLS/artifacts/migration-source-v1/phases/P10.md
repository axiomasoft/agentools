# P10 — Перенос в ERP-контур + анализ offline-разрыва (отчёт применимости)

## Phase Context

Финальная фаза плана (метка `DR-01` §K — «P5 перенос ERP»; прежний номер фазы — P5, см. карту
переименования `plan.md` §4). Перенос паттерна на Dart-контур ERP Axioma: адаптеры портов поверх
контрактов контура, сценарии из канона продукта, продуктовые векторы — и затем анализ применимости

ревизия» (D19/D62/D72) либо эскалация с адресатом-item'ом фазы P8, а НЕ повод поправить по месту.
