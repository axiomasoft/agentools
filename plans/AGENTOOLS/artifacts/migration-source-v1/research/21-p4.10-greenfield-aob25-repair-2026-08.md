## 1. Корень повторного отказа

P4.13 требует от каждой behavior-pair ровно один наблюдаемый counterfactual во входе
`given`/`script`. У `audit-004/104` их два:

1. `/given/driver_state/audit_export/mapping_version`:
   `revision-2026-08` ↔ `otel-semconv-1.27`;
2. `/given/tools/0/description`: различаются строки `Call when`.

Первый diff — предмет AOB-25: версия mapping отдельного export-adapter обязана меняться
независимо от ревизии. Второй diff — посторонний stimulus: модель видит разный tool descriptor,
поэтому различие результата нельзя однозначно приписать mapping version. `RAG:—
(repo-grounded: structural diff audit-004/104; 08_audit-observability.md:201–204)`.

## 2. Greenfield-инвариант владельца

AgenTools создаётся с нуля. Коммиты промежуточного корпуса — история разработки, но не
опубликованный API и не вход миграции. Поэтому корректность текущего тестового контракта имеет
приоритет над байтовым сохранением случайной формулировки draft-fixture. Здесь не нужны:

- legacy-ветка для старой `description`;
- alias/migration layer;
- assertion «файл обязан остаться равен прежнему commit», если прежний байт создаёт второй
  counterfactual.

Сохраняются только уже принятые продуктовые инварианты: single-rule pair D156, exact-one
structured evidence D159, замороженная норма AOB-25 и граница write-set текущего P4.13.
`RAG:— (repo-grounded: owner refinement 2026-08-04; plan.md D156/D159)`.

## 3. Выбранный repair

Обе половины получают одну нейтральную четырехстрочную `description`:

```text
Purpose: Экспортирует проверяемую запись аудита.
Call when: Нужно проверить экспорт аудита через отдельный адаптер.
Required arguments: value.
Example: demo_probe({"value":"audit"})
```

Другие поля `given.tools` и весь `script` остаются одинаковыми. Negative сохраняет
`mapping_version=revision-2026-08`, то есть ошибочную привязку mapping к ревизии; positive —
`mapping_version=otel-semconv-1.27`, то есть отдельно версионированный adapter mapping. `expect`
остаётся адресным oracle и не участвует в вычислении input-diff. После правки structural diff
обязан содержать ровно один pointer:
`/given/driver_state/audit_export/mapping_version`. `RAG:— (repo-grounded:
08_audit-observability.md AOB-25; fixtures README audit_export contract)`.
