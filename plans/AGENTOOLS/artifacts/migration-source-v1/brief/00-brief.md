## 1. Исходная задача (2026-07-07)

Спроектировать и построить **универсальный переиспользуемый слой agent + tools + сценарии**
для всей продуктовой экосистемы, а не отдельную фичу одного продукта.

Контуры-потребители, названные владельцем:

- **FlexCRM** (Laravel, ядро CoreX, PHP): сотрудник на главном экране пишет или наговаривает
  «сформируй отчёт о проделанной работе…» → агент матчит намерение на зарегистрированные
  доменные инструменты, вычищает лишнее, показывает preview и кнопку «Отправить отчёт», после
  подтверждения пишет в БД.
- **AiFina / AiResto** (Dart: Serverpod cloud / Shelf local, ядро AxiomaErpSdk): главбух
  спрашивает «кто ходил в отпуск в этом месяце», «сформируй отчёт по параметрам»; локальная
  установка опционально ходит в облачный MCP.
- Далее — FlexStore / FlexCMS и другие продукты экосистемы.

Ключевые способности, заявленные владельцем: intent → выбор инструмента или цепочки;
**интерактивные уточнения** в стиле AskUserQuestion (варианты ответа, «правильно ли я понял?»);
**preview + подтверждение** перед write-действиями; multi-tool сценарии; идемпотентность;
полный аудит. Отдельно: голос как вход (наговорил → то же самое, что напечатал).

Вход разведки — первичный анализ в `90_inbox/primary_analysis_agent_tool_unified.md`.

## 2. Решения владельца, зафиксированные на чекпойнтах 2026-07-07

- **Архитектура — protocol-first гибрид:** языконезависимая спека + два тонких нативных SDK
  (PHP и Dart). Python-мост/LiveKit как единое ядро — отклонить; Rust/FFI-ядро — отклонить.
- **Имя пакета — `AgenTools`** (слитно), выбрано владельцем вместо шорт-листа модели;
  «AigentTools» отклонён фактами (домен и slug заняты живым продуктом).
- **Всё приватно:** спека и оба SDK — в приватном репозитории; дистрибуция своя
  (composer-репозиторий / RegHub). «Открыть позже можно всегда, обратно — нельзя».
- **PHP-first:** порядок реализации PHP SDK → Dart SDK (Flex-контур уже в исполнении,
  Axioma-контур ещё не стартовал).
- **AgenTools не становится третьим рантаймом:** у обоих контуров уже есть спроектированные
  agent-слои (`corex/ai`, `axioma_assistant`/`axioma_mcp`) — они **реализуют** контракты
  AgenTools, а не заменяются им. Ни второго реестра инструментов, ни обхода AiGateway/ToolGuard.
- **Голос — отдельный edge-канал:** STT → тот же текстовый протокол; LiveKit нужен только
  для потокового live-диалога и подключается позже мостом.
- **LLM — через нативные шлюзы рантаймов**, не через MCP sampling.

## 3. Требования и границы, названные владельцем

- Наблюдаемость и полный audit trail; детерминированное превью; идемпотентность write;
  строгая типизация контрактов; contract testing (общие фикстуры + conformance-гейт);
  human-in-the-loop; headless/API-first.
- **Протокол не предполагает большие модели:** локальный контур AiResto — малые LLM через
  Ollama / OpenAI-совместимый API + подробные описания инструментов.
- Кода в vault-папке плана не пишем: реализация идёт в код-репозитории по фазам.
- Внешние факты — только через RAG с источником; без источника — `[UNVERIFIED]`.
