## Решение

**Дом conformance-адаптера PHP — `php/conformance/`, вместе с SDK, а не в `conformance/adapters/php/`.** Альтернатива (рядом с эталонным адаптером) отклонена: адаптер импортирует классы SDK, то есть потребовал бы автозагрузку `php/vendor` из дерева раннера — раннер узнал бы про composer-окружение SUT, чего harness-протокол специально избегает (адаптер запускается ОТДЕЛЬНЫМ процессом, `DR-01` §J1); плюс адаптер обязан меняться вместе с публичным API пакета, и в одном каталоге это видно одним диффом. `conformance/adapters/reference/` остаётся домом эталона, который принадлежит раннеру и SDK не импортирует
