## Решение

**Каталог ревизии — `spec/revisions/2026-08/` без суффикса `-draft`;** статус ревизии живёт в её `README.md` (`draft` → `frozen`), freeze выполняет гейт фазы P5 (B) + git-тег. Переименование каталога после релиза (механика D3) отменено — supersedes D3 в этой части. **Consequences:** платим тем, что имя каталога перестаёт нести стадию — `2026-08` читается одинаково и в `draft`, и во `frozen`, поэтому единственным носителем стадии становится строка README, и её рассинхрон с фактическим тегом виден только глазами (машинного гейта на «тег есть, а README говорит `draft`» в плане нет — цена удерживается жёстким порядком шести шагов D62). Возврат к механике D3 после первого закоммиченного `$id` невозможен без переписывания всех схем, примеров и golden-файлов ревизии — то есть отмена односторонняя

## Почему

`$id` каждой схемы содержит имя ревизии (`RAG:— (repo-grounded: tools/spec_lint.py:82 — expected_id = https://agentools.dev/schema/<revision_name>/<file>)`) → переименование переписывало бы все схемы, примеры и golden-файлы
