# Закрытие фазы P1

> Не править руками: это генерируемый вид.

## Контракт фазы

**Контракт фазы (contract-first).** Потребляет: audit, current tree, frozen
`2026-08`, conformance/release evidence AGENTOOLS и package-quality baseline. Производит:
digest-bound baseline, trust/threat model, compatibility/support policy, guarantees catalog,
migration inventory и resource/benchmark protocol. Границы: не меняет runtime behavior,
не объявляет pre-1.0 API stable и не выдаёт baseline RED за новую regression.

## Произведено

- P1.1 — Зафиксировать воспроизводимый pre-refactor baseline: Reusable baseline collector; machine-readable immutable baseline manifest; human report with exact green/red/unavailable matrix, counts, dependencies, public-surface candidates, archive lists, environmental limits and known anomalies.
- P1.2 — Заморозить trust boundaries, data flows и threat/misuse model: `threat-model-v1.md` with assets, trust boundaries, data flows, threat/misuse catalog, owner mapping, proof expectations and residual-risk register.
- P1.3 — Определить compatibility/support policy и migration inventory: Versioned compatibility/support policy and complete migration/consumer-notification inventory suitable as inputs to P2–P10 and the final release dossier.
- P1.4 — Заморозить guarantees, non-guarantees и proof ownership: Normative guarantee/non-guarantee catalog that downstream item specs can cite by stable ID and P10 can reconcile against actual receipts.
- P1.5 — Заморозить resource envelope и провести cross-contract gate P1: Resource-envelope/benchmark contract, complete P1 cross-contract coverage report, and versioned PLAN1 Exported-contract rows ready for P2–P10 consumption.
