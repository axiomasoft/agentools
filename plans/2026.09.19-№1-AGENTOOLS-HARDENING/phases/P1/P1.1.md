### P1.1 — Зафиксировать воспроизводимый pre-refactor baseline

**Intent:** Создать один stdlib-only baseline collector и снять из disposable clean worktree digest-bound отчёт о тестах, conformance, package checks, public symbols, dependency trees и archive contents до runtime/API refactoring.
**Why:** Текущий `tools/ci_gate.py` гоняет только четыре conformance-слоя, а CI не вызывает PHP static analysis, Dart analyzer, companion tests и package/archive checks; без отдельного baseline будущий RED неотличим от inherited defect. `RAG:—` (`.github/workflows/ci.yml`, `tools/ci_gate.py`, package manifests).
**Scope Included:** Recorded source commit/tree status and tool versions; exact command/exit/duration records for spec/conformance, PHP test+analysis, Dart core analyze+test, Dart MCP companion analyze+test, manifest validation and dry-run/archive probes; test/vector counts; Composer/Dart dependency locks; PHP namespace classmap and Dart barrel exports; actual package archive listings; explicit classification `green`, `red`, `unavailable` without repair.
**Scope Excluded:** Fixing a failed check; changing runtime/package metadata; asserting release support from one local runtime; network benchmark; publication; copying `vendor/`, `.dart_tool/`, caches or credentials into evidence.
**Inputs:** `plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/audit-verdicts.md` · `plans/AGENTOOLS/root/contracts/package-quality-baseline.md` · `spec/revisions/2026-08/README.md` · `.github/workflows/ci.yml` · `tools/ci_gate.py` · `conformance/sdks.json` · `php/composer.json` · `php/composer.lock` · `dart/agentools/pubspec.yaml` · `dart/agentools/pubspec.lock` · `dart/agentools_mcp_dart/pubspec.yaml` · `dart/agentools_mcp_dart/pubspec.lock`
**Files:** `tools/hardening_baseline.py` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/artifacts/P1-baseline.json` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/P1-baseline.md`
**Required Reads:** 1) `plans/AGENTOOLS/root/contracts/package-quality-baseline.md` 2) `.github/workflows/ci.yml` 3) `tools/ci_gate.py` 4) `conformance/sdks.json` 5) `php/composer.json` 6) `dart/agentools/pubspec.yaml` 7) `dart/agentools_mcp_dart/pubspec.yaml` 8) `spec/revisions/2026-08/README.md`.
**Implementation Rules:** Collector is stdlib-only and runs declared commands in a `mktemp -d` disposable worktree at the recorded commit; every command stores argv, cwd, exit code, duration, selected stdout/stderr digest and disposition. A non-zero command is baseline evidence, not automatic item failure; failure to launch/finish a declared probe or an unexplained mutation outside the two evidence outputs is item failure. Secret/environment values are allowlisted by name and never stored. Archive inventories come from actual Composer/Dart packaging probes, not `find` approximations. Public-symbol inventory distinguishes PHP PSR-4 reachability from intentional API and Dart top-level barrel exports from `lib/src`; it does not call either stable. Current working-tree changes remain untouched.
**Code Guidance:** CLI: `capture --output <json> --report <md>` and `verify --baseline <json>`. Canonical JSON uses sorted keys and SHA-256; Markdown is a projection whose tables name exact JSON paths. Create/remove only the exact temporary worktree returned by `mktemp`; cleanup is in `finally`, and failed cleanup is reported. Do not shell-interpolate repository data; subprocess argv is a list. Package dry-run may be RED because `publish_to: none`/proprietary metadata; preserve that outcome verbatim. Record unknown historical dates such as `1970-01-01` as `known_anomaly`, never normalize history in this item.
**Validation:** `python3 -m py_compile tools/hardening_baseline.py`; focused unittest coverage for deterministic ordering, timeout/unavailable/red classification, secret redaction and path-safe temp cleanup; run `python3 tools/hardening_baseline.py capture --output plans/2026.09.19-№1-AGENTOOLS-HARDENING/artifacts/P1-baseline.json --report plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/P1-baseline.md`; run `python3 tools/hardening_baseline.py verify --baseline plans/2026.09.19-№1-AGENTOOLS-HARDENING/artifacts/P1-baseline.json`; JSON/report record the same commit and inventory digest; every declared probe has a terminal disposition; product paths outside `tools/hardening_baseline.py` are byte-identical to the pre-capture anchor.
**Deliverables:** Reusable baseline collector; machine-readable immutable baseline manifest; human report with exact green/red/unavailable matrix, counts, dependencies, public-surface candidates, archive lists, environmental limits and known anomalies.
