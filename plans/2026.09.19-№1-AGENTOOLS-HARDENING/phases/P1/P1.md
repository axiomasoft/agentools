# P1 — Baseline, threat model и контракт guarantees

## Phase Context

P1 замораживает воспроизводимый дорефакторинговый baseline и превращает
проверенные находки аудита в версионированные входы P2–P10: trust/threat model,
матрицу compatibility/support, каталог guarantees/non-guarantees и resource envelope.
Красный pre-existing check остаётся baseline-фактом и не толкуется как regression;
исправления runtime, package boundary и release pipeline принадлежат P2–P10.

> **Контракт фазы (contract-first).** Потребляет: audit, current tree, frozen
> `2026-08`, conformance/release evidence AGENTOOLS и package-quality baseline. Производит:
> digest-bound baseline, trust/threat model, compatibility/support policy, guarantees catalog,
> migration inventory и resource/benchmark protocol. Границы: не меняет runtime behavior,
> не объявляет pre-1.0 API stable и не выдаёт baseline RED за новую regression.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: spec-fixtures-conformance · php-dart-parity · release-baseline
> Live or Irreversible: no
> Audit Intent: direct-close-eligible

## Scope Included

Clean-checkout test/conformance/package baseline; public-symbol, dependency и archive inventory;
trusted/partially-trusted/untrusted boundaries; attacker и integrator-misuse cases; dated
compatibility/support matrix; migration/notification inventory; guarantees и explicit
non-guarantees; implemented/missing resource limits; repeatable benchmark protocol без
абсолютного PR threshold.

## Scope Excluded

Runtime fixes; новые storage schemas/adapters; package moves; API removal/deprecation;
release publication; official MCP conformance execution; claim `exactly-once external effects`;
принятие audit SQL/API sketches без дизайна owning phase.
