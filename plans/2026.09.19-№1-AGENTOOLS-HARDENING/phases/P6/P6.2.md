### P6.2 — Собрать generated semantic manifest и exact-set PHP/Dart drift gate

**Intent:** Построить digest-qualified `semantic-profile/v1` из normative `2026-09`, снять фактические профили PHP/Dart и сделать missing/extra/mismatch красным CI-гейтом без генерации SDK source.
**Why:** Current PHP/Dart constants are manually maintained and already have unequal literal coverage; PHP↔Dart equality alone is not normative. DR-02 rejected SDK codegen but explicitly left structural freshness as the replacement gate. `RAG:—`.
**Scope Included:** Deterministic manifest extractor; schema/version/source digests; SDK profile contract/exporters; exact-set comparator for codes/categories/default and case retryability/states/transitions/envelope versions/bounds/outcomes/capabilities/spec revision; stable sorted JSON report; missing/extra/mismatch diagnostics; manual-DTO freshness checks and mutants.
**Scope Excluded:** Generating PHP/Dart source; public export/layout decisions; changing P2–P5 behavior; JCS byte oracle; official MCP suite; accepting aliases/unknown rows to make the report green; translating titles/detail strings as parity requirements.
**Inputs:** P6.1 `semantic-parity-v1.md`, successor revision/corpus and migration inventory · executed PHP/Dart P2–P5 code and receipts · current error/state/capability implementations · DR-02 and D11.
**Files:** `tools/semantic_manifest.py` · `spec/revisions/2026-09/semantic-manifest.json` · `php/src/Error/**` · `php/src/Action/**` · `php/src/Confirmation/**` · `php/src/Idempotency/**` · `php/src/Persistence/**` · `php/conformance/semantic_profile.php` · `php/tests/Semantics/**` · `dart/agentools/lib/src/errors/**` · `dart/agentools/lib/src/journal/**` · `dart/agentools/lib/src/confirmation/**` · `dart/agentools/lib/src/idempotency/**` · `dart/agentools/lib/src/persistence/**` · `dart/agentools/conformance/semantic_profile.dart` · `dart/agentools/test/semantics/**` · `conformance/bin/semantic-parity` · `conformance/tests/SemanticParityTest.php` · `conformance/reports/semantic-parity.json`.
**Required Reads:** 1) P6.1 contract/revision/corpus/migration 2) DR-02 §4/§6 and D11 3) PHP/Dart error, action, confirmation, idempotency, persistence and capability code actually present after P2–P5 4) `schema/error.json`, successor rule index and hardening case manifests 5) current conformance adapter/report conventions 6) `plans/2026.09.19-№1-AGENTOOLS-HARDENING/research/P6-design.md` §§2.
**Implementation Rules:** The manifest is regenerated from normative sources and checked for zero diff. SDK profiles are assembled from production constants/types and declared capabilities, not copied test JSON. Exact-set means both directions; unknown extra is red. Case-level retryability is compared separately from the code default. All rows include source addresses and input digests. Report ordering is deterministic. Human titles/localization are excluded, while safe context-key sets are included. No reflection/source parser may silently skip an unreadable file. Source generation and network reads are forbidden. A mismatch keeps the item non-green; editing the manifest by hand is forbidden.
**Code Guidance:** Prefer small language-native profile builders returning plain JSON-compatible maps. Keep the comparator in `conformance/` language-neutral at the data boundary. Print `missing`, `extra`, and field-level `mismatch` arrays. Make one mutant per semantic family so a comparator that only counts rows cannot pass.
**Validation:** Manifest regeneration produces no diff; PHP and Dart profiles validate against `semantic-profile/v1`; comparator reports `missing=[]`, `extra=[]`, `mismatch=[]`; mutants for missing code, wrong category, inverted retryability, removed transition, changed bound and unsupported capability are each red; a hand-added SDK row is red; full PHP/Dart analysis/tests stay green; no generated PHP/Dart files or runtime manifest loader is introduced; plan lint adds no ERROR.
**Deliverables:** Generated digest-qualified semantic manifest, actual PHP/Dart profile exporters, deterministic exact-set parity report and proved manual-DTO drift gate.
