# P6 — Cross-language semantics, errors, canonicalization и MCP conformance

## Phase Context

P6 превращает исполненные контракты P2–P5 в самодостаточную candidate-ревизию
`2026-09` и один generated semantic profile для PHP/Dart. Фаза доказывает exact-set
паритет кодов, states, transitions, retryability, bounds и capabilities, а JCS-байты
сверяет с независимым RFC/upstream oracle, а не только PHP с Dart.

Official MCP остаётся отдельным доказательным контуром: каждая строка requirements
`2026-07-28` получает applicability-класс, но исполняются только сценарии,
достижимые через public boundary `agentools_mcp_dart`. Полной MCP SDK/server certification
фаза не заявляет.

> **Контракт фазы (contract-first).** Потребляет: терминальные P2–P5 contracts, case manifests,
> SDK surfaces и receipts; frozen `2026-08`; official MCP/JCS pins D11. Производит:
> candidate `2026-09`, generated semantic manifest, PHP/Dart exact-set profile receipt,
> independent JCS receipt, official MCP applicability/receipts и интегрированный P6 gate.
> Границы: не меняет `2026-08`, не генерирует SDK source, не владеет package exports,
> не минтит public tag и не называет partial official scenarios certification.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: successor-spec-fixtures · php-dart-semantic-profile · error-boundary · jcs-oracle · official-mcp-client-applicability · conformance-gate
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: normative sources generate a digest-bound profile, independent oracle decides canonical bytes, and every official MCP requirement row remains visible; Review=full.

## Scope Included

Самодостаточная successor-ревизия и migration; unified error/state/transition/capability
semantics; generated semantic-profile projection; PHP/Dart exact-set drift gate; RFC 8785 corpus,
UTF-16/string/number/invalid-input coverage и independent oracle; official MCP conformance exact pin,
applicability matrix, bounded Dart-client driver/raw receipts; candidate revision lock; Agentools
successor conformance и P7–P10 residual handoff.

## Scope Excluded

Правки `spec/revisions/2026-08/**` и `fixtures/2026-08/**`; генерация PHP/Dart source;
полная MCP client/server SDK, PHP MCP transport, сервер, auth/prompts/resources ради зелёного
suite; MCP certification/Tier claim; package exports/layout; mutation/fuzz/100M-number stress;
CI supply-chain policy; public tag/registry upload; изменение P2–P5 feature ownership.
