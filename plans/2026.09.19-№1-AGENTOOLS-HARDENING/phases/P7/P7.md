# P7 — Intentional public API и package boundaries

## Phase Context

P7 превращает фактическую PHP/Dart достижимость в намеренный
consumer contract: каждый supported symbol/export входит в exact manifest,
имеет production consumer и behavioural proof, а accidental reachability классифицируется
как advanced, testkit, reference или internal.

Граница доказывается manifests, autoload/exports, реальными archive listings
и чистыми consumers. Массовый перенос каталогов не нужен: PHP reference/test
implementations становятся dev-only, Dart testkit — отдельной library внутри
package, а `agentools_mcp_dart` сохраняется отдельным optional package. `RAG:—`.

> **Контракт фазы (contract-first).** Потребляет: P1 baseline/compatibility/guarantees,
> terminal P6 semantic manifest и residuals, current manifests/source/consumers. Производит:
> package-boundary contract, exact PHP/Dart API manifests, dev-only testkit/reference contours,
> archive allowlists, migration map и built-artifact consumer receipt. Границы: не меняет
> P2–P6 semantics, не публикует package и не берёт P8/P9/P10 gates.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: php-psr4-autoload · dart-library-exports · core-testkit-reference · mcp-companion · package-archives · clean-consumers
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: exact target/actual manifests, built-archive consumers and migration compilation expose accidental exports and package leakage; Review=full.

## Scope Included

Repository-wide current/target API inventory; stable/advanced/testkit/reference/internal taxonomy;
PHP namespace/autoload/archive boundary; Dart explicit public libraries and exports; `agentools_mcp_dart`
optional dependency boundary; in-memory/fixed/reference implementations; deterministic API manifests and
BC drift gate; archive allowlists; compatibility/deprecation map; examples and clean consumers installed
only from locally built package artifacts.

## Scope Excluded

Semantic redesign P2–P6; source generation; framework/Laravel/Flutter adapters; new production storage
adapter; mutation/fuzz/performance depth; CI permissions/matrices/SBOM/provenance; registry identity,
public tag/upload or hosted dependency selection; moving directories only for aesthetics; claiming that
private/local archive evidence equals a public release.
