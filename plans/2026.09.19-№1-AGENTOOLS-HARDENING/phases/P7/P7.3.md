### P7.3 — Сузить Dart exports и закрепить testkit/MCP companion boundary

**Intent:** Сделать public Dart libraries exact по P7.1: core barrel экспортирует только supported core, test doubles доступны через отдельную `agentools_testkit.dart`, а MCP transport остаётся в companion package.
**Why:** `agentools.dart` транзитивно экспортирует `InMemory*` и `FixedClock`, а package layout делает каждую top-level `lib/*.dart` намеренной public library; current broad barrel скрывает границу. `RAG:—`.
**Scope Included:** Core/testkit public libraries; explicit transitive export allowlists; `show`/`hide` where needed; in-memory/fixed implementations; class modifiers where compatibility permits; no external `lib/src` imports; pure-Dart core; optional MCP companion import/dependency boundary; API docs/migration examples; actual-vs-target manifest.
**Scope Excluded:** Flutter support; new MCP features or certification; changing P2–P6 semantics; publishing to pub.dev; choosing a hosted source/version for the current path dependency; new runtime package split without measured contract benefit; P8 fuzz and P9 dependency matrix.
**Inputs:** P7.1 contract/target/inventory · executed P2–P6 Dart surfaces/receipts · current Dart pubspecs, barrels, tests, conformance and MCP companion · P1 compatibility policy · D12.
**Files:** `dart/agentools/pubspec.yaml` · `dart/agentools/lib/agentools.dart` · `dart/agentools/lib/agentools_testkit.dart` · `dart/agentools/lib/src/**` · `dart/agentools/test/**` · `dart/agentools/conformance/**` · `dart/agentools/API.md` · `dart/agentools/UPGRADING.md` · `dart/agentools_mcp_dart/pubspec.yaml` · `dart/agentools_mcp_dart/lib/**` · `dart/agentools_mcp_dart/test/**` · `dart/agentools_mcp_dart/API.md` · `api/package-surface-v1.json`.
**Required Reads:** 1) P7.1 deliverables 2) P1 compatibility/migration contract 3) P2.4/P3.4/P4.4/P5.4/P6.5 Dart receipts 4) Dart official package layout, libraries and Effective Dart sources in `plans/2026.09.19-№1-AGENTOOLS-HARDENING/research/P7-design-rag.md` 5) both Dart pubspecs and complete export/import graph 6) D12.
**Implementation Rules:** `agentools.dart` exports no testkit/reference implementation. `agentools_testkit.dart` is the only supported test-double entrypoint and core never imports it. Files under `lib/src` are implementation and never used as consumer contract. `agentools_mcp_dart` imports only supported `package:agentools/...` libraries, never core `src`; core has no `mcp_dart` or Flutter dependency. The companion path dependency remains a local/private release blocker explicitly handed to P9/P10; P7 does not infer a public registry decision.
**Code Guidance:** Prefer explicit domain barrels with `show`/`hide` over one accidental everything barrel. Use Dart class modifiers only when the P1 compatibility delta proves they do not silently break intended implementers. Keep compatibility forwarding libraries only when target contract names a removal window. Generate actual export closure and docs inventory; do not declare `lib/src` technically inaccessible—prove supported imports by lint and consumers instead.
**Validation:** `dart format --output=none --set-exit-if-changed .`, `dart analyze`, `dart test` in both packages; P6 successor conformance/MCP applicable scenarios stay green; `dart doc` has zero unresolved public-reference warnings; target-vs-actual Dart surfaces exact; main core import cannot name testkit classes, testkit import can; analyzer rejects fixture importing another package's `lib/src`; core dependency graph has no Flutter/MCP/testkit edge; companion has no implementation import; undeclared export mutant makes the gate red.
**Deliverables:** Narrow Dart core API, explicit testkit library, preserved optional MCP companion boundary, exact export manifest, API docs and migration evidence.
