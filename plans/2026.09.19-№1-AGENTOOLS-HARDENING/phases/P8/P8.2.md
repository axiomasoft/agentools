### P8.2 — Построить deterministic property, differential и bounded fuzz corpus

**Intent:** Реализовать один language-neutral generated corpus с replay/shrink/promotion protocol и доказать PHP/Dart byte/error/state parity на JCS, token/binding, fingerprints, limits and state transitions.
**Why:** Два SDK могут согласиться на одном дефекте, а случайный seed без generator/runtime/corpus identity не воспроизводит failure. P6 даёт независимый JCS oracle, но оставляет mutation/fuzz depth P8. `RAG:—` и RFC evidence в `research/P8-design-rag.md`.
**Scope Included:** Explicit stable PRNG; versioned generators for valid typed values and hostile raw bytes; boundary partitions; metamorphic relations; P6 independent-oracle reuse; cross-language adapters; deterministic shrinkers; minimized counterexample receipts; immutable promoted regressions; bounded parser/schema/token/fingerprint/state-machine/resource-negative cases.
**Scope Excluded:** Treating PHP or Dart as sole oracle; indefinite/coverage-guided fuzz service; automatic golden rewrite from SDK output; generating secrets/PII; new protocol codes or bounds; performance timing; storage interleavings owned by P8.4.

**Implementation Rules:** Generated bytes originate from a repository-owned explicitly versioned PRNG and generator, not host randomness. A run identity includes manifest/generator/corpus digests, seed, case index, PHP/Dart/tool/runtime versions, locale/timezone and input SHA-256. Valid typed generators and hostile raw-byte mutators are separate. PHP/Dart outcomes compare canonical bytes, stable codes and normalized state—not exception text/order. Shrinking preserves the violated predicate; a failure cannot turn green until its minimized input is promoted with provenance or the product/contract owner resolves it. Bounds from P1 are exercised at `limit-1/limit/limit+1`; no generator may allocate past its declared cap.
**Code Guidance:** Prefer composable stdlib Python generators/shrinkers so both SDKs consume identical bytes. Cover JCS idempotence and formatting invariance, Unicode/duplicate-key/number rejection, token one-bit mutations and time boundaries, binding/fingerprint separation, and legal/illegal state transitions. Stream large corpora. Never normalize raw-invalid input through a permissive parser before the target API sees it. A mismatch report prints case ID, seed, input/output digests and first byte/state delta.
**Validation:** Same manifest+seed run twice produces byte-identical case order and receipt; replay by `(generator_version, seed, case_index)` reproduces the exact input; injected PHP-only and Dart-only defects each make differential red; malformed raw cases reach both parsers and match stable rejection class; independent JCS expected bytes remain authoritative; shrinker produces a strictly smaller still-failing case and promotion replay runs before new generation; extended corpus is bounded and streaming; full existing conformance/PHP/Dart suites remain green; plan lint adds no ERROR.
**Deliverables:** Reproducible cross-language property/fuzz harness, versioned corpus and promoted regressions, minimized failure protocol and digest-bound parity receipt.
