### P8.3 — Убить critical PHP/Dart mutants и закрепить calibrated mutation gates

**Intent:** Доказать чувствительность ordinary suites к обязательному security/storage fault catalog, добавить scoped Infection для PHP и выпустить честные language-specific mutation baselines без общего vanity score.
**Why:** Coverage показывает выполнение строк, но не то, что authorization, replay, fencing, collision and bounds assertions различают опасную реализацию. PHP имеет AST-aware Infection, а доступный Dart tool применяет regex/text replacements; их проценты несопоставимы. `RAG:✅` в `research/P8-design-rag.md`.
**Scope Included:** Critical semantic mutant catalog for P2–P7; PHP Infection dev tool/config/coverage reuse; calibrated PHP MSI and covered-MSI by named scope; digest-bound PHP/Dart patch mutants in disposable trees; survivor/equivalent/exclusion triage; exact kill receipts; ordinary test additions needed to kill valid mutants.
**Scope Excluded:** Mutating generated/declarative/vendor/migration files for score; counting compile-invalid, setup-error or timeout as a critical kill; generic Dart regex score as release proof; arbitrary 100% MSI; product semantic fixes outside owning phase; CI workflow integration.

**Implementation Rules:** Infection is a locked dev dependency and mutates only named non-generated critical PHP namespaces. Reuse fresh coverage+JUnit inputs; `timeoutsAsEscaped=true`, zero unexplained timeout allowance. Set `minMsi`/`minCoveredMsi` only after a green baseline and reviewed equivalent/noise triage; persist exact source/config/tool digests and never lower a floor silently. The shared critical catalog is stronger than aggregate MSI: every valid `critical` mutant must be killed by an ordinary test in both applicable SDKs. Dart and SQL/adapter semantic mutants are exact digest/anchor-qualified patches applied only in `mktemp`; generic `mutation_test` percentage is not a gate. Compile-invalid, unapplied, skipped, timeout and harness-error outcomes are non-green.
**Code Guidance:** Include removal/inversion of authorization, dual-control, token signature/time/binding/consume, lease token CAS/capability deny, event collision/expected-version/redaction, JCS ordering and hard bounds. The runner verifies clean source before/after, records patch digest, command, exit, duration and killed-by test IDs, and refuses stale anchors. Every exclusion has a narrow symbol, reason, reviewer and compensating proof; blanket directories in protocol code are forbidden.
**Validation:** Original suites green before mutation; every named critical mutant is applied exactly once and killed in PHP/Dart where applicable; one deliberately weakened ordinary assertion produces a surviving-mutant RED self-test; stale/ambiguous patch, compile-invalid mutant and timeout are RED rather than killed; Infection report has calibrated floors, zero unexplained timeout and no unreviewed critical survivor; repeated run on unchanged source/config reproduces mutant identity/outcome sets; owner workspace digest unchanged after patch runs; plan lint adds no ERROR.
**Deliverables:** Locked PHP Infection configuration and baseline, cross-language critical mutant catalog/runner, zero-critical-survivor receipt and explicit equivalent/exclusion review.
