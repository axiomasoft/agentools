### P10.5 — Принять private RC и выпустить non-authorizing G-RELEASE decision packet

**Intent:** Зафиксировать техническое принятие exact private RC и сформировать immutable decision packet, по которому owner позже может разрешить или отклонить конкретную public release branch.
**Why:** Private fitness and public authority answer different questions. A green dossier must not create a tag, registry upload, legal identity or credential grant by implication. `RAG:✅` permanence/channel facts в `research/P10-design-rag.md`.
**Scope Included:** Independent dossier verification; private acceptance record; exact subject/checksum/SBOM/provenance/source/tree binding; release notes; final DoD; public eligibility blockers; proposed identities/channels/version/tag/actions; credential/capability prerequisites; rollback/revocation limits; packet digest and expiry/invalidation triggers; offline verifier and negative fixtures.
**Scope Excluded:** Accepting/superseding D5 on the owner's behalf; minting `[OWNER-GATE:G-RELEASE]`; changing `LICENSE`, visibility or package identity; resolving Dart MCP path dependency; creating/pushing tag; Packagist/pub.dev/GitHub release; credentials/OIDC; modifying repository settings; claiming deletion/rollback of a published version.
**Inputs:** P10.4 dossier/residual ledger · P10.2 release notes/docs · P10.3 consumer receipt · P9 exact subjects/checksums/SBOM/provenance/attestation state · D4, D5, D12, D14, D15 · current source/tree identity.
**Files:** `tools/private_release_gate.py` · `tests/tools/test_private_release_gate.py` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/artifacts/P10-private-rc-acceptance.json` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/artifacts/P10-g-release-request.json` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/P10-private-rc-acceptance.md` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/P10-g-release-decision-packet.md`.
**Required Reads:** 1) P10.4 machine dossier and residual ledger 2) P10.2 docs/release notes and P10.3 consumer receipt 3) P9.3–P9.5 exact subject/SBOM/provenance/attestation records 4) D4, proposed D5, D12, D14 and D15 5) official Packagist, Dart, SemVer and GitHub release constraints in `research/P10-design-rag.md` 6) current `LICENSE`, manifests, repository visibility/capability observations.
**Implementation Rules:** Private acceptance is a technical record bound to one source tree and exact subject digests; any relevant byte, receipt, risk or capability change invalidates it. G-RELEASE packet is a request, never a grant. It must list a finite branch per public action with exact registry/repository identity, version/tag, subject digests, legal/support decision reference, credential path, preconditions, compensating response and irreversibility warning. Unknown identity/channel/version, unresolved D5, proprietary/public mismatch, `publish_to: none`, MCP path dependency or absent capability leaves public eligibility false without making private acceptance red. A future grant must cite the packet digest and cannot widen it. Public execution requires a separate exact owner invocation; P10 performs none.
**Code Guidance:** Verify acceptance and request as separate schemas/objects. The verifier must reject `authorized=true` without owner evidence, wildcard channels/actions, mutable subject identity, stale dossier, missing public blocker and any command transcript showing tag/upload/release. Record inability to delete or rewrite published versions as a release consequence, not a promised rollback.
**Validation:** Private acceptance is GREEN only when P10.4 private readiness is GREEN, P10.3 exact subjects pass and required evidence is fresh; packet rehash independently matches all subjects/materials; fixtures reject stale/mutated/wildcard/self-authorized requests; public eligibility is false under current D5/path-dependency/private metadata and does not affect private PASS; `git tag`, GitHub release and Packagist/pub.dev state are unchanged; no publication credential is read; repository diff contains no legal-identity or `publish_to` change; final DoD and plan lint are green.
**Deliverables:** Digest-bound accepted private-RC record, final release notes/DoD, explicit public blocker set and immutable non-authorizing G-RELEASE decision packet for optional future owner scope.
