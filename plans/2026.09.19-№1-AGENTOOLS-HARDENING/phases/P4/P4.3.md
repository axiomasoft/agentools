### P4.3 — Реализовать PostgreSQL lease adapter, takeover и retention

**Intent:** Ввести в оба SDK durable PostgreSQL adapter на injected SQL, который атомарно выдаёт один lease, делает takeover по истечении, CAS-complete/fail и чистит только completed rows.
**Why:** Unique `(tenant_id, tool_name, idempotency_key)` plus token CAS is the only proof across workers. In-memory and unfenced SQLite leave the crash window open. `RAG:—`; SQL semantics — `research/P4-design-rag.md`.
**Scope Included:** Versioned SQL schema; PHP PDO PostgreSQL adapter; Dart adapter over injected SQL executor; takeover/heartbeat SQL; completed-only cleanup; concurrency, stale-worker, fingerprint, TTL and collision tests; SQLite reference store brought to the same CAS contract or clearly marked insufficient for P4.3 close.
**Scope Excluded:** Coordinator public API; capability catalog behavior beyond storing whatever complete/fail the caller sends; event journal; adding Composer/pub driver libraries; applying SQL to an owner production database; CI matrix ownership (P9).

**Implementation Rules:** First acquire is `INSERT … ON CONFLICT (tenant_id, tool_name, idempotency_key) DO NOTHING RETURNING`. Takeover is `UPDATE … SET lease_token, attempt=attempt+1, lease_until WHERE in_progress AND lease_until <= :now RETURNING`. Complete/fail/heartbeat `UPDATE … WHERE in_progress AND lease_token=:token RETURNING`. Empty RETURNING is lost-lease / lost-takeover; do not SELECT-after-empty to authorize an effect. Cleanup is `DELETE WHERE state='completed' AND expires_at < :now`. Partial unique indexes on unexpired rows are forbidden. In-memory cannot close this item. PHP `suggests` `ext-pdo_pgsql`; Dart does not add a `postgres` dependency. Shared SQL file is the schema SSOT. Tenant isolation is part of the primary key.
**Code Guidance:** Two connections/executors in one test process are sufficient for the arbiter; a stale-worker test keeps the old lease object after takeover. Parameterize `:now` from injected Clock. Do not log tokens or full result payloads. Follow D8’s injected-SQL pattern; do not introduce a second persistence style.
**Validation:** Shared SQL applied to ephemeral PostgreSQL; 50 concurrent acquires yield exactly one lease and 49 in-flight; expired lease yields one takeover; stale complete/fail/heartbeat yield lost-lease; fingerprint mismatch does not overwrite; cleanup negative test fails if it deletes in-progress or unexpired completed rows; PHPUnit postgres group and Dart SQL tests green; `cd php && composer analyse`; `cd dart/agentools && dart analyze`; `git diff --exit-code -- spec/revisions/2026-08`; plan lint adds no ERROR.
**Deliverables:** Durable fenced store adapter, versioned SQL, takeover/retention evidence, and an honest SQLite reference disposition.
