# P4 — Lease/fencing idempotency и external-effect guarantees

## Phase Context

P4 заменяет split `resolve/complete(request)` на acquire/heartbeat/complete(lease)/fail(lease)
с opaque fencing token, monotonic attempt, takeover и compare-and-swap. Она явно ограничивает
обещание: arbitrary external effect не становится exactly-once из-за local store. Наблюдаемые
IDE-10 состояния остаются тремя; capability policy живёт в coordinator, не в физике строки.

> **Контракт фазы (contract-first).** Потребляет: P1 guarantees/clock/resource policy.
> Производит: lease/fencing contract, PHP/Dart API, durable PostgreSQL adapter,
> takeover/heartbeat/failure semantics, `IdempotencyCoordinator`, downstream capability model
> и documented guarantees. Границы: outbox/inbox не встраиваются; ALC epoch — P5;
> shared spec/error revision — P6; final exports — P7; mutation/fuzz depth — P8.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: coordinator · idempotency-store · downstream-tool · postgresql-pdo · result-replay
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: фаза изменяет durability promise; crash/takeover/stale-worker tests и full review обязательны.

## Scope Included

Acquire/in-progress/completed storage; request fingerprint collision; opaque fencing token/attempt;
heartbeat; lease expiry/takeover; CAS complete/fail; deterministic result replay; retention of
completed rows; native-key/read-before-write/compensatable/at-most-once-only/unknown capability
policy; ambiguous failure handling; PHP/Dart parity и storage contract tests; wiring supported
invoke path through `IdempotencyCoordinator`.

## Scope Excluded

Exactly-once claim; orchestration/saga engine; automatic retries для unknown high-risk tool;
downstream product-specific compensation logic; editing `spec/revisions/2026-08/**`; P3 token
consume; P5 event journal/epoch; final package exports; public release; live owner-database
migration.
