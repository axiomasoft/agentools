# P2 — Safe confirmation boundary и context-rich authorization

## Phase Context

P2 заменяет поддерживаемый per-call security API на additive `ConfirmationService`: вызывающий
передаёт только token и фактические аргументы, а actor, clock, descriptor, policy, proposal,
approval evidence и authorization context приходят из внедрённых доверенных портов. Текущий
`ConfirmationProtocol` остаётся временным expert/legacy primitive для совместимости, но перестаёт
быть рекомендуемой integration boundary и не может использоваться reference consumers.

> **Контракт фазы (contract-first).** Потребляет: P1 threat/compatibility/guarantee contracts,
> frozen `2026-08` и current PHP/Dart call surface. Производит: versioned confirmation-security
> contract, общий adversarial case manifest, typed trusted-context model, safe service в PHP/Dart,
> migrated reference consumers и parity receipt. Границы: P3 владеет token wire, durable consume
> и key lifecycle; P5 — journal/event persistence; P6 — новой spec revision/error registry;
> P7 — окончательным public export/removal решением.

> **Phase Assurance | v1.**
> Impact: security-external
> Integration Seams: authentication-provider · policy-store · descriptor-registry · action-journal-projections · confirmation-coordinator · php-dart-parity
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: shared adversarial cases, package-level negative tests и migrated consumers проверяют
> обход safe facade; Review=full из-за изменения authorization/public-contract semantics.

## Scope Included

Safe prepare/commit facade; authenticated actor and authorization-context providers; current descriptor
registry; authoritative policy resolver; journal-backed proposal/approval read ports; immutable binding
tuple for tenant, proposal/version, action/tool, arguments, descriptor, policy revision, required approvals
and commit principal; policy-selected dual control/quorum; stable refusal codes; additive deprecation and
migration for PHP/Dart; shared adversarial cases and reference-consumer migration.

## Scope Excluded

Token serialization/algorithm/key rotation; cross-process atomic consume; production storage adapters/DDL;
atomic event append and audit export; general error registry/JCS oracle; final package split/export removal;
public release; claim that dependency injection protects against a malicious trusted composition root.
