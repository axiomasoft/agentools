**Why:** Typed contracts alone не устраняют caller-controlled `ConfirmationProtocol::commit`; supported path должен физически не иметь параметров для clock, actor, descriptor, authorizer, policy mode/revision, approval evidence или dual-control override. `RAG:—`.

**Implementation Rules:** Public service accepts no injectable per-call security value. Prepare obtains actor/time/descriptor/policy/authorization target from trusted dependencies, fails if commit principal cannot be resolved, persists a bound confirmation record through the declared port, then invokes the legacy protocol. Commit verifies signed token, exact authoritative record, arguments and current descriptor; validates policy identity/revision/compatibility and approval evidence; then sends a context-rich request to the injected authorizer. Missing/unknown/mismatch/deny is fail-closed with stable code/category and redacted external context. Current process-local spend remains explicitly baseline-partial until P3; service must not claim durable replay safety. Frozen `2026-08` bytes stay unchanged.
