### P9.1 — Зафиксировать CI/supply-chain contract, immutable tool lock и capability inventory

**Intent:** Создать единственный нормативный контракт для untrusted CI и trusted private RC, зафиксировать immutable actions/tools и снять read-only capability baseline GitHub.
**Why:** Workflow hardening без trust-plane model переносит privilege через checkout/artifacts, а licensed GitHub features могут отсутствовать и давать ложный GREEN. `RAG:✅` в `research/P9-design-rag.md`.
**Scope Included:** Event-to-trust-plane matrix; top-level deny-by-default permissions; job-level minimums; fork/untrusted-code/artifact/cache rules; full-length action SHA policy; timeout/concurrency/retention/log-redaction requirements; immutable pins/digests for Syft, OSV-Scanner, Gitleaks and GitHub actions; read-only inventory of repository visibility, default workflow permissions, branch protection, environments and security/attestation capabilities; machine-readable policy checker and baseline finding.
**Scope Excluded:** Workflow implementation beyond policy fixtures; changing repository/org settings; enabling paid features; secrets or OIDC grants; dependency/runtime matrices; archive/SBOM production; publication.
**Inputs:** `.github/workflows/ci.yml` · `php/composer.lock` · `dart/agentools/pubspec.lock` · `dart/agentools_mcp_dart/pubspec.lock` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/root/contracts/compatibility-support-v1.md` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/decisions/D14-ci-private-rc-evidence.md`.
**Files:** `plans/2026.09.19-№1-AGENTOOLS-HARDENING/root/contracts/ci-supply-chain-v1.md` · `.ci/supply-chain-lock.json` · `.gitleaks.toml` · `.osv-scanner.toml` · `tools/ci_policy.py` · `tests/tools/test_ci_policy.py` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/P9-ci-capabilities.md`.
**Required Reads:** 1) `plans/2026.09.19-№1-AGENTOOLS-HARDENING/research/P9-design.md` and `research/P9-design-rag.md` 2) `plans/2026.09.19-№1-AGENTOOLS-HARDENING/phases/P1/P1.closed.md` 3) `plans/2026.09.19-№1-AGENTOOLS-HARDENING/phases/P7/P7.closed.md` and `phases/P8/P8.closed.md` 4) `.github/workflows/ci.yml` and every referenced local action/script 5) GitHub Actions secure-use, permissions, artifact-attestation and repository capability primary sources cited in `research/P9-design-rag.md` 6) `plans/2026.09.19-№1-AGENTOOLS-HARDENING/decisions/D4-release-gate.md` and `plans/2026.09.19-№1-AGENTOOLS-HARDENING/decisions/D14-ci-private-rc-evidence.md`.
**Implementation Rules:** Untrusted PR jobs receive no write token or secrets, never execute fork code under `pull_request_target`/privileged `workflow_run`, and do not feed caches/artifacts into trusted RC. Start every workflow at `permissions: {}` and grant only per-job minimum. Every third-party action reference is a reviewed full 40-hex commit SHA with human-readable version comment; CLI binaries/images are checksum/digest locked. Capability inventory distinguishes `available-enabled`, `available-disabled`, `unavailable-plan` and `unknown` with observation time/source. The checker itself never changes GitHub state and emits no token/secret values.
**Code Guidance:** Parse workflow YAML structurally, including reusable-workflow calls, token persistence, event/ref guards, expression-bearing action refs and cache/artifact flows. Keep the lock file canonical and schema-versioned. Test malicious fixtures for mutable tags, implicit permissions, privileged untrusted checkout, missing timeout/concurrency, unpinned containers and credential persistence. Baseline finding may be RED before P9.2; it must enumerate every current violation without weakening policy.
**Validation:** Unit fixtures prove every forbidden pattern turns policy red and approved least-privilege fixtures pass; lock entries resolve to immutable-form references and include source/license/checksum metadata; repository capability report is reproducible from read-only API/CLI evidence and redacted; current workflow baseline lists mutable `actions/checkout@v4`/`shivammathur/setup-php@v2`, absent explicit permissions/timeouts/concurrency and single-PHP coverage; no GitHub setting or workflow file changes in this item; plan lint adds no ERROR.
**Deliverables:** Versioned CI/supply-chain contract, immutable dependency lock, executable policy checker, security scanner configs and honest capability baseline ready for P9.2–P9.5.
