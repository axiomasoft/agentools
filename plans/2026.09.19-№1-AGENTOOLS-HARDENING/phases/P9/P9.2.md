### P9.2 — Реализовать hardened CI matrices и точное отображение P8 evidence tiers

**Intent:** Превратить P1 compatibility contract и P8 workload tiers в least-privilege, bounded CI workflows с отдельными supported, lowest/latest и security lanes.
**Why:** Один PHP 8.4 job не доказывает заявленную поддержку, а смешивание matrix-resolved locks с release inputs делает candidate неповторимым. `RAG:✅` Composer/Dart semantics в `research/P9-design-rag.md`.
**Scope Included:** Hardened primary PR/push CI; extended scheduled/manual workflow; exact P8 `focused`/`bounded`/`extended` mapping; PHP supported runtimes plus fresh `--prefer-lowest --prefer-stable` and latest resolution; Dart supported runtimes plus fresh `pub downgrade` and latest resolution for both packages; generated drift, conformance, package/consumer, OSV and Gitleaks lanes; job timeouts, concurrency cancellation, cache-key isolation, artifact retention; Dependabot action/dependency update configuration where supported; machine-readable CI map.
**Scope Excluded:** Release-candidate bytes; SBOM/provenance/attestation; mutation of GitHub security settings; claiming unavailable dependency review/secret scanning; matrix-generated lock commits; public publication; universal timing thresholds.
**Inputs:** `plans/2026.09.19-№1-AGENTOOLS-HARDENING/root/contracts/ci-supply-chain-v1.md` · `.ci/supply-chain-lock.json` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/root/contracts/compatibility-support-v1.md` · `root/contracts/adversarial-verification-v1.md` · `artifacts/P8-adversarial-gate.json` · package manifests/locks.
**Files:** `.github/workflows/ci.yml` · `.github/workflows/extended.yml` · `.github/dependabot.yml` · `tools/ci_matrix.py` · `tests/tools/test_ci_matrix.py` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/artifacts/P9-ci-map.json` · `plans/2026.09.19-№1-AGENTOOLS-HARDENING/findings/P9-ci-map.md`.
**Required Reads:** 1) P9.1 outputs and `decisions/D14-ci-private-rc-evidence.md` 2) `phases/P1/P1.closed.md` and executed support/resource contracts 3) `phases/P8/P8.closed.md` and executed P8 aggregate receipt 4) `phases/P7/P7.closed.md` and package manifests/locks 5) official Composer `validate`/`--prefer-lowest` and Dart `pub downgrade` evidence in `research/P9-design-rag.md` 6) all existing workflows and local CI scripts.
**Implementation Rules:** Exact runtime versions come from the executed P1 support contract, not duplicated literals without a generated equality check. Lowest/latest jobs run in fresh disposable copies, discard regenerated locks and can never supply P9.3 inputs. PR uses `focused` plus required bounded semantic/security gates; main uses `bounded`; scheduled/manual uses `extended`. `release-candidate` is not an alias for extended and belongs to P9.5. Timing blocks only on P8 matching fingerprints; mismatch stays explicit `baseline_pending`. OSV scans all three lockfiles with the pinned scanner. Gitleaks scans history and worktree with redacted output. An unavailable GitHub-native feature remains a visible capability gap, not an omitted/pass row.
**Code Guidance:** Generate matrix rows from the support contract and validate exact set equality. Use separate caches per runtime/lock digest/trust plane; do not save a cache from untrusted fork code for a privileged consumer. Preserve raw child receipts and artifact digests. Keep the quick PR graph bounded and move full mutation/fuzz/storage/benchmark workloads to declared extended/release tiers without silently dropping critical P8 IDs.
**Validation:** Workflow policy checker is fully green; event/permission tests prove fork PRs lack secrets/write scopes and no privileged event executes untrusted checkout; matrix validator reports exact supported/lowest/latest rows for PHP and both Dart packages; lowest/latest fixtures demonstrate fresh resolution and no source lock mutation; P8 map has `missing=[]`, `extra=[]` and exact command/input digests per tier; OSV/Gitleaks positive fixtures turn red without leaking secrets; timing mismatch cannot pass/fail; unavailable native features are reported; no release artifact or public side effect occurs.
**Deliverables:** Hardened CI/extended workflows, dependency-update configuration, exact generated matrix/tier map and CI receipt inputs for P9.5.
