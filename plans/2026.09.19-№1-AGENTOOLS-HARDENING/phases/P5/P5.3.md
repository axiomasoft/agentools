### P5.3 — Реализовать PostgreSQL event adapter, IDENTITY position и keyset pagination

**Intent:** Ввести в оба SDK durable PostgreSQL adapter на injected SQL, который атомарно пишет батч, назначает seq/global_position, классифицирует replay/collision и читает keyset-страницы.
**Why:** Unique `(tenant_id, action_id, seq)` plus classify-before-INSERT is the only proof across workers. In-memory and SELECT-then-INSERT SQLite leave lastSeq/append races and silent id no-ops. `RAG:—`; SQL semantics — `research/P5-design-rag.md`.
**Scope Included:** Versioned SQL schema (stream header + events); PHP PDO PostgreSQL adapter; Dart adapter over injected SQL executor; IDENTITY `global_position`; `SELECT … FOR UPDATE` header lock; keyset load; concurrency, collision, replay, pagination and gap tests; SQLite reference log brought to the same contract or clearly marked insufficient for P5.3 close.
**Scope Excluded:** JournalAppender public wiring beyond using the port; audit-export policy behavior beyond persisting whatever committed events the caller sends; adding Composer/pub driver libraries; applying SQL to an owner production database; CI matrix ownership (P9); OpenTelemetry SDK.

**Implementation Rules:** Lock the stream header, classify replay/collision/partial, then INSERT. Do not `ON CONFLICT DO NOTHING RETURNING` as the classifier. `global_position` is `GENERATED ALWAYS AS IDENTITY`; callers omit it; `RETURNING` supplies seq and position. Content hash is computed before INSERT and stored; it MUST NOT include IDENTITY/seq columns. Cleanup/DELETE of events is forbidden on the application path (ALC-31). Pagination is `seq > :after ORDER BY seq ASC LIMIT :limit`, never `OFFSET`. PHP `suggests` `ext-pdo_pgsql`; Dart does not add a `postgres` dependency. Shared SQL file is the schema SSOT. Tenant isolation is part of the primary key. In-memory cannot close this item.
**Code Guidance:** Two connections/executors in one test process are sufficient for the arbiter. Parameterize time from injected Clock only for `ts` / `occurred_at`, never for order. Do not log payloads or tokens. Follow D8/D9 injected-SQL pattern; do not introduce a second persistence style. Unique violations are safety nets that fail the transaction, not success paths.
**Validation:** Shared SQL applied to ephemeral PostgreSQL; 50 concurrent appends yield exactly one winner and 49 version conflicts; two-event batch rolls back entirely on conflict; identical replay inserts zero rows; payload collision does not overwrite; page N+1 starts at last seq of page N with no gaps; PHPUnit postgres group and Dart SQL tests green; `cd php && composer analyse`; `cd dart/agentools && dart analyze`; `git diff --exit-code -- spec/revisions/2026-08`; plan lint adds no ERROR.
**Deliverables:** Durable EventStore adapter, versioned SQL, concurrency/pagination evidence, and an honest SQLite reference disposition.
