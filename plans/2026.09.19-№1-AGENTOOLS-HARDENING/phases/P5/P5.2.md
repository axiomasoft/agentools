**Implementation Rules:** `append` returns assigned seq range, global_position of the last event, and `appended` vs `idempotent_replay`. `load` is keyset `seq > after` with default 500 / hard max 1000. In-memory still classifies collision vs replay so unit tests fail if they ignore the hash. `EventLog.append(ActionEvent)` is absent from the production interface; test helpers may wrap a one-event batch for frozen three-field assertions. In-memory is testkit/reference-only and cannot be a production constructor default. Do not log payloads or tokens. Do not expose `Any` expected version.
**Code Guidance:** Keep committed `ActionEvent` as the ALC-5 envelope. Generate event ids with CSPRNG UUID/ULID in helpers, never `ev-{id}-{seq}`. Shared error spellings come from P5.1. Prefer the existing `Canonicalizer` for the collision digest. Test fakes live only in test files.
