# Knowledge golden evidence

The registered `knowledge-journey` e2e partition requires all exact PostgreSQL
journey cases plus the separately reported host-hook contract cases and scoped
static analysis. Missing dependencies, empty cases, skips, missing isolation,
wrong adapter kinds, absent hashes and invented educational qualification fail.
The report distinguishes local-host-e2e, real PostgreSQL/tsvector index, scripted
extraction/owners/model, and unqualified live OCR/provider capabilities.

Focused development checks accept `--filter ClassOrMethod`:

```sh
python3 extensions/knowledge/tests/Golden/unit.py --filter HostValidationTest
python3 conformance/platform/knowledge/run.py --filter GoldenJourneyTest
```

Filtered output is focused evidence and does not claim the whole e2e acceptance.
`gold.json` is independent of source documents; changing source formulas/units
without changing the host gold fails even when source mapping/hashes are valid.
No LLM judge or invented numeric threshold certifies a domain fact.

The P8.4 implementation receipt carries a review handoff with upstream raw
receipts, engine evidence, original source-hash files and computed SHA-256 values.
Any unavailable historical original is named as missing; references and a covers
list cannot substitute for actual review consumption. Review dispatch and its
one correction limit belong to the coordinator. All original findings and
historical qualification limits remain explicit.
