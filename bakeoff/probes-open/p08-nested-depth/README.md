# p08-nested-depth

**Проверяет:** вложенность объектов ≥6 уровней (`l1`…`l6`) + `patternProperties` на листовом
уровне — лимиты `SEP-2106` (E5) существуют именно потому, что глубокая вложенность и обилие
подсхем — DoS-вектор; проба измеряет, где генератор упирается в лимит рекурсии/стека.

**Терпимым поведением считается:** генератор строит вложенный тип на всю глубину без падения
по стеку и без «выпрямления» иерархии, а также сохраняет `patternProperties` как словарь
(map/dict), а не отбрасывает его.
