# p02-unknown-keyword

**Проверяет:** терпимость к незнакомому **ключевому слову схемы** — `x-agentools-note` на
уровне свойства `note` (образец: `spec/revisions/2026-07-draft/schema/side-effect.json` уже
несёт вендорные ключи `x-default-confirmation`/`x-d7-mapping`). Ключ обязан игнорироваться
генератором JSON Schema — не путать с колонкой round-trip (потеря **свойства документа**).

**Терпимым поведением считается:** генератор строит тип для `note` как обычно, не падая на
неизвестном ключе `x-agentools-note` и не отбрасывая само поле `note`.
