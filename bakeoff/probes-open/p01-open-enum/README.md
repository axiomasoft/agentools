# p01-open-enum

**Проверяет:** приём открытых перечислений AgenTools (E2) — `oneOf` из известных `const`-веток
плюс fallback-ветка `string` с шаблоном `^<product>\.[a-z0-9_]+$`. `valid.json` намеренно
использует значение из fallback-ветки (`crm.custom_step`), а не из известных `const`, чтобы
проверить саму механику расширения, а не тривиальный случай.

**Терпимым поведением считается:** генератор строит тип, принимающий как известные `const`,
так и произвольную строку по шаблону (например, enum с open-ended вариантом или просто
`string`-поле), не отбрасывая значение и не падая на `oneOf` с разнородными ветками.
