# p09-ref-local

**Проверяет:** относительный `$ref` между файлами ревизии (`schema.json` → `common.json#/$defs/Id`)
без сетевого доступа — ловушка `2026-07-draft`: генератор обязан резолвить `$ref` по локальному
файлу песочницы, а не пытаться скачать `$id` (`https://agentools.dev/...`) из сети (запрет
автодереференса сетевых `$ref`, E5).

**Терпимым поведением считается:** генератор находит `common.json` рядом со `schema.json` и
строит тип `id` по правилу `Id` (паттерн snake_case), не делая сетевых запросов и не падая с
ошибкой резолва.
