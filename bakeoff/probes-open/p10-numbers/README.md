# p10-numbers

**Проверяет:** три режима чисел, проблемных для сериализации ES6/JCS: `amount_minor` — integer
в минорных единицах (копейки, типичный вход финансовых сумм в AiFina/AiResto); `big_integer` —
значение за пределами `Number.MAX_SAFE_INTEGER` (2^53-1), где JS-числа теряют точность;
`scientific` — экспоненциальная запись `1e21`, которая в JS сериализуется НЕ как `1e+21`, а как
строка с полным разложением (JCS-смежная ловушка round-trip).

**Терпимым поведением считается:** сгенерированный тип сохраняет `big_integer` без потери
точности (или явно типизирует его как строку/BigInt, если язык это предлагает) и не меняет
числовое значение `scientific` при round-trip сериализации.
