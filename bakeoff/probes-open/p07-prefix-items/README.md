# p07-prefix-items

**Проверяет:** `prefixItems` + `items: false` — кортеж фиксированной длины (пара хешей
до/после side-эффекта). `prefixItems` заменяет tuple-форму `items` из draft-07 в 2020-12;
генераторы, знающие только старую форму, могут молча деградировать до произвольного массива.

**Терпимым поведением считается:** генератор строит тип кортежа из двух строк (либо
хотя бы массив строк без потери элементов), не падая на `prefixItems` и не путая его с
обычным `items`-массивом.
