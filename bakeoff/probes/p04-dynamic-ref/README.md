# p04-dynamic-ref

**Проверяет:** `$dynamicRef`/`$dynamicAnchor` — рекурсивная самоссылающаяся структура (дерево
узлов `id` + `children`). Экзотика 2020-12 (`DR-01` §J6): ожидаемый массовый исход —
`crash`/`not-supported`, но это ДОЛЖНО быть измерено прогоном, а не выведено из документации.

**Терпимым поведением считается:** генератор либо строит рекурсивный тип (`ok`), либо падает
предсказуемо с понятной ошибкой (`crash`/`not-supported`) без порчи остального вывода — оба
исхода фиксируются в логе с точным сообщением.
