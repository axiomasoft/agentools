# p06-if-then-else

**Проверяет:** `if`/`then`/`else` (тип шага диктует обязательные поля) и `dependentSchemas`
(поле `approval` обязательно, если `side_effect = write`) — приём уже используется в `Step`
(`scenario.json`) и является нормативным для условных полей профиля инструмента (01/TCP).

**Терпимым поведением считается:** генератор строит тип со всеми полями веток `if`/`then`/`else`
(union или все поля опциональными на уровне типа — условность проверяется рантаймом, не
типом), не отбрасывая `approval` из-за вложенности в `dependentSchemas`.
