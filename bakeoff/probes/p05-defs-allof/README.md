# p05-defs-allof

**Проверяет:** `$defs` + `allOf`-композиция базового типа (E5) — `NamedEntity` расширяет
`Entity` через `allOf` с локальным `$ref`. Приём уже используется в спеке (`Step` из
`scenario.json` composed через `allOf`+`if/then`).

**Терпимым поведением считается:** генератор мержит поля обеих веток `allOf` в один тип
(`id`+`title`), не порождая дублирующих типов и не теряя поле из базовой ветки `Entity`.
