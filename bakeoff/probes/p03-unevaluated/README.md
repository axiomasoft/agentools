# p03-unevaluated

**Проверяет:** `unevaluatedProperties: false` на внешнем уровне `allOf`-композиции (J9 —
вариант схемы авторинга, закрытая схема). Опубликованные схемы этот ключ не несут вовсе; сам
ключ — экзотика 2020-12 (J6), и `unknown-key.json` по построению НЕ проходит валидацию против
этой схемы — это ожидаемо и является conformance-вектором J9 (документ с лишним ключом
отвергается закрытой схемой, но должен приниматься сгенерированным типом при round-trip).

**Терпимым поведением считается:** генератор строит тип по `allOf`-композиции, не падая на
`unevaluatedProperties`, и результирующий тип (не сама JSON Schema-валидация) не отбрасывает
`id`/`note` при генерации.
